دعوة ذكرى رشدي أباظة — ملفات GitHub Pages

ارفعي index.html مباشرة إلى جذر الـ Repository، ثم فعّلي GitHub Pages من Settings إن لم يكن مفعّلًا.

الأزرار:
- اكتب دعاء أو كلمة طيبة: يفتح نموذجًا؛ يمكن مشاركة النص عبر واتساب أو نسخه.
- شارك في ختمة القرآن: يفتح منصة ختمة الجماعية العربية. أنشئي ختمة جديدة هناك، اختاري تقسيم الأجزاء، ثم شاركي رابط الختمة الناتج مع المدعوين. الزر يفتح المنصة، لكنه لا ينشئ ختمة باسمك تلقائيًا.
- مشاركة الدعوة: يستخدم قائمة المشاركة في الهاتف أو ينسخ الرابط.

التاريخ: توفي رشدي أباظة يوم الأحد 27 يوليو 1980، وفق الهيئة العامة للاستعلامات.
